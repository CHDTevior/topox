Found one concrete silent finite-output hole: override `coarse_mask` is not required to be prefix-active, so the root anchor can be displaced from slot 0.

```python
anchor_indices = torch.tensor([[-1, 0, 2, 5]])
coarse_mask = torch.tensor([[False, True, True, True]])
joint_mask = torch.ones(1, 6, dtype=torch.bool)
```

With a normal `J=6` line skeleton, `T=4`, `local_radius=5`, this passes `src/models/graph_salad/pool_dynamic.py:533-560`, returns finite pooled outputs and finite aux losses, with `pooled_mask=[[False, True, True, True]]` and hard assignments only in slots `[1,2,3]`.

Why this is invalid: rule-based selection writes anchors contiguously from slot 0 and pads the tail (`src/models/graph_salad/pool_dynamic.py:140-155`), with sorted anchors from `graph_utils.py:457`. Override currently matches sorted/unique active anchors, but not the prefix slot contract. Add a per-sample `coarse_mask` prefix check.
