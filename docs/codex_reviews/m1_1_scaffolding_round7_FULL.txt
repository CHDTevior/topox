Q5. M1.2 forward compatibility.

Answer: GO at the GraphMotionBatch invariant level after Q3 cleanup. With the current code, M1.2 consumers can trust the listed load-bearing fields:

- batch.parent_indices[b]: list length equals num_joints[b], strict ints, valid connected single-root tree, root index 0, parent-before-child ordering.
- batch.adjacency[b,:nj,:nj]: finite float32, binary, symmetric, zero diagonal, exactly matches parent_indices edges; padded rows/cols are zero.
- batch.joint_mask[b]: bool, prefix-contiguous True then False, sum equals num_joints[b].
- batch.frame_mask[b]: bool, prefix-contiguous True then False, sum equals num_frames[b].
- batch.num_joints[b] / num_frames[b]: int64 [B], in range, mask-consistent.
- batch.fps[b]: float32 [B], finite and positive.
