Round-1 blocker verification
----------------------------

1. Assignment non-negativity check: SEALED.

Evidence:

- src/models/graph_salad/unpool.py:132 checks if (assignment < -1e-6).any().
- src/models/graph_salad/unpool.py:133-136 raises ValueError with an explicit DynamicGraphUnpool message.
- tests/test_unpool.py:130-139 constructs row [1.5, -0.5], which sums to 1 but contains a negative entry, and expects ValueError matching "negative entries".

Assessment:

- The tolerance is sensible for float32 assignment probabilities. It rejects real negative extrapolation while allowing sub-micro numerical noise.
- This is a proper fail-loud path, not a bare assert.
- This test is not tautological: the old row-sum-only contract would accept [1.5, -0.5] because the row sum is exactly 1.0. The new test would catch that old failure mode.

2. Assignment must be zero on padded coarse columns: SEALED.

Evidence:

- src/models/graph_salad/unpool.py:139 builds padded_col = ~coarse_mask with shape [B, C].
- src/models/graph_salad/unpool.py:142 computes padded_col_assign = assignment * padded_col.unsqueeze(1).to(assignment.dtype), broadcasting [B, 1, C] over [B, J, C].
- src/models/graph_salad/unpool.py:143-148 raises ValueError if the absolute max in padded coarse columns exceeds 1e-6.
- tests/test_unpool.py:141-151 uses coarse_mask = [[True, False]] and assignment row [0, 1] for a valid joint, then expects ValueError matching "coarse_mask=False columns".

Assessment:

- The semantics match the claim: the mask selects coarse columns where coarse_mask is False for each batch element, across all fine joints.
- The check is batch-aware because coarse_mask keeps its B dimension before unsqueeze.
- The test is not tautological: without the padded-column check, the test assignment has valid row sums and would not be rejected by the row-sum contract alone.

3. Mask-vs-features temporal kernel consistency: SEALED.

Evidence:

- src/models/graph_salad/unpool.py:182-191 sets s = self.temporal_stride and, for s > 1, applies repeat_interleave(s, dim=1) to fine_features and repeat_interleave(s, dim=-1) to frame_mask_down.
- src/models/graph_salad/unpool.py:193-194 then zeros invalid upsampled frames with the same repeated frame_mask_up.
- There is no executable F.interpolate call in src/models/graph_salad/unpool.py.
- tests/test_unpool.py:153-177 checks that down-frame 0 repeats into up-frames 0 and 1, while down-frame 1's invalid repeated frames are masked to zero and frame_mask_up is [[True, True, False, False]].

Assessment:

- Features and masks now use the same nearest-neighbour replication kernel: t_up maps to t_down = t_up // stride.
- Batch-size handling is shape-generic. repeat_interleave acts along the temporal dimension and preserves B/J/D dimensions.
- The path cannot silently truncate or wrap by itself; output length is exactly T_lat * stride.
- The odd/even original-length issue is handled upstream, not inside unpool: DynamicGraphPool raises if T % temporal_stride != 0 at pool_dynamic.py:650-654, and DeterministicGraphPool has the same divisibility guard at pool_deterministic.py:384-385. Since unpool has no target fine T argument, its explicit contract is [B, T_lat * stride, J, D].
- The test is meaningful for the old linear-interpolation bug: it requires up-frame 1 to equal the exact repeated value 5.0, not an interpolated blend with the invalid neighbor.
