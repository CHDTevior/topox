GO/NO-GO
================================================================================

M1.2 step 4 unpool.py: NO-GO for sealed DynamicGraphPool-compatible integration.

Reason:
  - Hard assignment itself is good enough, and zero-param contract is clean.
  - But deterministic pool is not yet an interchangeable drop-in for the sealed
    dynamic pool because it rejects legal padded finite-geodesic batches and its
    aux_losses schema is missing oracle keys.

Minimum fix list before GO:
  1. Align geodesic max-hop validation with dynamic: remove it or scope it to
     valid-valid pairs only.
  2. Return aux_losses keys mincut_cut, mincut_ortho, mincut, locality, entropy
     in deterministic, with zero constants on device=P.device and dtype=P.dtype.
  3. Add tests for aux schema parity, padded finite-geodesic parity, aux dtype
     under nondefault torch default dtype, and padded joint/slot zeroing.
  4. Optional hardening: replace fixed 1e6/2e6 argmin masking with +inf
     non-candidate masking after no-candidate rows are rejected.
