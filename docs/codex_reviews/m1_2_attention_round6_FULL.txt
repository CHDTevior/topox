**2. New Unsealed R12**

Yes: adjacency/geodesic consistency is not sealed. Exact malformed input that passes all current validators:

```python
adj = torch.tensor([[[0., 1., 0., 0.],
                     [1., 0., 1., 0.],
                     [0., 1., 0., 1.],
                     [0., 0., 1., 0.]]])
geo = torch.tensor([[[0., 1., 2., 2.],   # wrong: 0->3 should be 3
                     [1., 0., 1., 2.],
                     [2., 1., 0., 1.],
                     [2., 2., 1., 0.]]])
x = torch.randn(1, 4, 16)
mask = torch.ones(1, 4, dtype=torch.bool)
GraphAttentionBlock(16, 2, 32, dropout=0.0)(x, adj, geo, mask)
```

This is finite, symmetric, non-negative, integer-valued, diagonal-zero, and within `N-1`, so it passes. Silent failure: the geodesic additive bias treats endpoints of a 4-node line as 2 hops instead of 3, corrupting topology without raising.

Minimal fix sketch:

- `src/models/graph_salad/attention.py:37`: import `floyd_shortest_path`.
- After `attention.py:259-264`, compare `geodesic_dist` against `floyd_shortest_path(adjacency, node_mask)` on valid pairs only.
- Add `tests/test_graph_attention.py` case where the malformed `geo[0,0,3]=geo[0,3,0]=2.0` raises.
