Q4. has_rotations Special-Casing — NEEDS-FIX

has_rotations should be forced to torch.Tensor for this collate contract.

UnifiedMotionDataset returns Python bool at unified_dataset.py:316. Because
isinstance(True, int) == True, collate takes the scalar branch at
unified_dataset.py:359-360. In current PyTorch, torch.tensor([True, False])
is torch.bool, not a list.

So the comment at batch.py:55-57 is misleading. The synthetic test using
torch.tensor([True, True]) at test_scaffolding.py:42-43 is correct; I would
add an assertion that dtype is torch.bool.
