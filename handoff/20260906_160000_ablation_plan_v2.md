external retargeting pipeline (rejected 16:25Z) and not statistics borrowing (item 1 parked: position means encode geometry).

"random sub-skeleton" training is a near-free augmentation; only tree features (depth/hops), parents and the description subset change.

  3. rest-convention perturbation: multiply each joint's rest-delta by a fixed random small rotation per clip (demo rest frame follows);
  4. bone-length scaling +-20% of position channels and per-cell mean/std noise -> deployment statistics/proportion errors.
