# 预测目标消融终局报告:v-pred / x-pred / x-pred+decode-loss

日期 2026-08-14。数据集 `data/animo4d_L4TB_plus_human_v4b272neutral`,冻结 tokenizer `runs/holdout_vqvae_semantic_8card_v1/ep150_model.pt`,严格 unseen-topology 协议(`unseen_topology_v1`)。

## 0. 一句话结论

在 rectified flow 上,**x-pred + v-空间 loss 比 v-pred 在中段与高噪端全面更准(t=0.35 处误差低 25%),但在 t→1 的近干净端急剧劣化(最后一档差 25 倍)**;这个误差结构同时解释了 x-pred 为何 proj_err 一贯更低却采样能量偏高,也解释了为何**减少 ODE 步数(50→20)反而让 x-pred 更好**。加入 decode-back 几何损失(v4)是明确的负结果,与 RVQ snap 管线张力导致采样端能量暴走。

## 2. t-bin 误差结构(核心发现)

`scratch/_probe_xspace_tbin_error.py`,96 clip / 24 batch,两臂喂**同一噪声、同一 t、同一 cond**,比较 x-空间 masked MSE。RF 约定:`z_t = t·x + (1−t)·noise`,**t=1 为干净**。

| t | 1−t | xerr v-pred (A) | xerr x-pred (B) | **B/A** |
|---|---|---|---|---|
| 0.020 | 0.980 | 0.338523 | 0.340839 | 1.007 |
| 0.050 | 0.950 | 0.261683 | 0.237581 | 0.908 |
| 0.100 | 0.900 | 0.197577 | 0.163587 | 0.828 |
| 0.200 | 0.800 | 0.125213 | 0.096266 | 0.769 |
| **0.350** | 0.650 | 0.067030 | 0.050289 | **0.750** ← x-pred 最优 |
| 0.500 | 0.500 | 0.035128 | 0.026510 | 0.755 |
| 0.650 | 0.350 | 0.016753 | 0.013074 | 0.780 |
| 0.800 | 0.200 | 0.006227 | 0.005348 | 0.859 |
| 0.900 | 0.100 | 0.002145 | 0.002179 | 1.016 |
| 0.950 | 0.050 | 0.000807 | 0.001094 | 1.356 |
| 0.980 | 0.020 | 0.000222 | 0.000683 | 3.074 |
| **0.995** | 0.005 | 0.000023 | 0.000597 | **25.678** ← x-pred 崩坏 |

**读法**:B/A < 1 表示该 t 处 x-pred checkpoint 更准。这是关联而非因果——两臂训练历史并非 RNG 逐位相同。

**机理**:采样端要做 `v̂ = (x̂₀ − z_t)/(1−t)`。t→1 时分母趋零,x̂₀ 的微小误差被 1/(1−t) 放大;t=0.995 处放大 200 倍。v-pred 直接输出 v̂ 没有这个除法。反过来在高噪端(小 t),x̂₀ 是良态目标而 v 的方差大,所以 x-pred 占优。

这与最初的先验框架("ε 在低噪端好、高噪端 x̂₀ 方差爆炸;x₀ 预测在高噪端稳;v 平衡两端")**方向一致,但在 RF 参数化下不稳定的那一端翻到了 t→1**(DDPM 语境里对应 ᾱ_t→1 的近干净端)。

## 5. 三方横向对照(各自终点,cfg2.0 / 50 步)

| 物种 | v2 @ep290 | v3 @ep194 | v4 @ep30(负结果) |
|---|---|---|---|
| HML3D_Human | 0.662 / 1.146 | **0.517 / 1.137** | 2.688 / **5.071** |
| PZ_Caracal_Male | 0.553 / 0.436 | **0.329 / 0.554** | 0.518 / 4.223 |
| PZ_Grey_Seal_Female | 0.798 / 1.467 | **0.408 / 1.419** | 0.761 / 1.504 |
| PZ_Red_Kangaroo_Female | 0.666 / 3.214 | **0.372 / 3.750** | 1.495 / **32.612** |
| PZ_West_African_Lion_Male | 0.566 / 2.145 | **0.320 / 2.030** | 0.343 / 2.847 |
| **proj_err 均值** | 0.649 | **0.389** | 1.161 |

格式:proj_err / speed_ratio(GT=1.0)。

- **x-pred 的 proj_err 全面优于 v-pred**(均值 0.389 vs 0.649,低 40%),五个物种无一例外。这与 §2 中段占优一致——离散码本流形上的点主要由中段的重建精度决定。
- **能量校准两臂接近**,都在动物快动作上偏高(袋鼠 3.2–3.8 倍)。x-pred 略高,符合它近干净端误差更大的预期。
- **v4 是明确的负结果**:proj_err 均值 1.161(比 v2 差 79%),袋鼠 speed_ratio **32.6 倍**。decode-back 几何损失优化的是连续解码路,而推理走的是 RVQ snap 路,两者张力把采样端能量推爆。注:v4b 曾在无量化的 VAE latent 上成功用过同类损失,差异在于**有没有量化这一步**。

## 7. 局限与未决

1. **等进度对照未达成**:§2 是 v2@199 对 v3@194。要严格对照需让 v3 从 ep194 resume 并把存档点对齐到 ep199(代码改动 + 约 2.3 小时)。趋势本身(25 倍量级)不可能由 5 个 epoch 造成,但严格性上这是缺口。
2. **v2 未跑满 300**:止于 ep298,最终 ckpt ep289。其 val 自 ep240 起在小数点后第三位横盘(0.19835@230 → 0.19663@240 → 0.19805@297),四个渲染观测点的 proj_err 也无方向性变化,判断为**已收敛,缺失的 epoch 不影响结论**。
3. **两臂 epoch 数不同**(v2 到 298 / v3 到 199),横向比较建立在"两者都已进入各自收敛平台"的前提上。若要发表级严格性,应补一次等 epoch 的对照。
4. 视觉裁决未纳入本报告——所有 gif 已交付,以人眼判定为准(本项目视觉优先于 metric)。
