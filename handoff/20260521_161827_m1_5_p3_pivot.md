## §1 Frozen Pred Root Cause (codex + my sanity, conf HIGH)

### What we observed
4 trained variants (dyn/det/none/soft) all produce PRED with `speed_ratio = 0.1-1.3%` of GT motion speed → essentially static skeletons. Visualization confirms (qa_animate gifs show PRED frozen, GT moving).

### Root cause (refined through 12-cell sanity ablation matrix on Bat in-distribution training)

Reasoning:
1. Initial codex audit (thread 019e4ae0): blamed KL collapse + posterior drift. PARTIALLY right but missed real cause.
2. My ablation: showed even `w_kl=0` reproduces frozen on multi-clip → KL not necessary.
3. Codex revised audit (thread 019e4b11): identified MY sanity bug — `w_kl=0` removes KL penalty but train forward still uses `z = mu + eps·std` (stochastic). Real test of "no KL" requires `vae(batch, sample=False)`.
4. Re-ran with `--latent_train mean` flag → unlocks the truth.

**Final diagnosis** (high confidence):

> Multi-clip training with stochastic latent (`z = mu + ε·std`) creates a frozen-pred attractor: decoder learns to IGNORE noisy z and output mean-pose. Recon loss is happy because static-pose-with-offset has finite L1 distance to any GT pose.

This is amplified by:
- Multi-clip averaging effect (more clips → more averaged-out motion)
- Pool + temporal_stride=4 + KL adds a second-layer collapse mechanism
- Loss weights (w_pos=w_vel=1) don't strongly penalize static enough

NOT caused by:
- Architecture (single-clip overfit reaches ratio=0.94)
- Data scarcity alone (1-clip works; data quantity ≠ root cause but amplifies)
- z=mu eval (eval is symptom, not cause)

## §4 Code Changes Needed (NOT YET APPLIED)

### File 1: `src/models/graph_salad/losses.py`
Add `masked_speed_mag` function:
```python
def masked_speed_mag(pred_pos: torch.Tensor, gt_pos: torch.Tensor,
                     joint_mask: torch.Tensor, frame_mask: torch.Tensor) -> torch.Tensor:
    """B prong: penalize |pred_speed_mag - gt_speed_mag| per (j, t).
    Anti-frozen: when pred is static (||pred_diff||=0) but gt moves (||gt_diff||>0),
    this term forces motion energy regardless of direction.
    """
    if pred_pos.shape[1] < 2:
        return torch.zeros((), device=pred_pos.device, dtype=pred_pos.dtype)
    pp_d = (pred_pos[:, 1:] - pred_pos[:, :-1]).norm(dim=-1)  # [B,T-1,J]
    gp_d = (gt_pos[:, 1:] - gt_pos[:, :-1]).norm(dim=-1)
    fm_pair = frame_mask[:, :-1] & frame_mask[:, 1:]  # [B,T-1]
    mask = joint_mask.unsqueeze(1) & fm_pair.unsqueeze(-1)
    mf = mask.to(pp_d.dtype)
    return ((pp_d - gp_d).abs() * mf).sum() / mf.sum().clamp(min=1.0)
```
Add to `compute_total_loss`:
```python
# Around the existing pos/vel/etc components:
losses["speed_mag"] = masked_speed_mag(pred_pos, gt_pos, joint_mask, frame_mask)
total = ... + weights.get("speed_mag", 0.0) * losses["speed_mag"]
```
